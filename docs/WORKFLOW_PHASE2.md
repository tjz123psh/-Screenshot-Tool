# 第二批：同一次截图的继续处理

本批在第一批可靠性基础上实现可编辑会话、统一输出设置和资源保护。总任务持续推进；本批安装后继续版本化交付，不在这里关闭总目标。

## 用户入口

- 普通 Enter 保留快速完成行为；Ctrl+Enter 明确进入预览继续处理。也可在「截图与输出」启用区域截图后始终预览，默认不改变旧习惯。
- 查看器提供继续编辑、裁切、OCR、翻译；识别结果窗口可返回同一张图查看或编辑。
- 会话编辑支持选中移动/调整图形、修改旧文字、删除对象、画新标注、再裁切和撤销重做；应用修改不等于保存，未输出版本需要保留可见持有者或明确确认放弃。
- 打开已有 PNG/JPEG/WebP 后仅把它作为平面背景；可以添加新标注，不能恢复其中已经烘焙的旧文字和箭头。

## 一致性与隐私

- 文档有稳定编号和单调版本；保存、复制、识别/翻译结果绑定对应版本。编辑后上一版的输出状态不能冒充当前版。
- 旧识别正文和手工修改不清空，但会标明来自修改前图片；默认操作要求显式识别当前版本，迟到任务不得覆盖新版。
- 可编辑源图只包含原始选区，不保留选区外桌面；对象快照不含输入法预编辑文字、光标或选择控制点，包含当前可见的实色遮挡。
- 跨进程编辑会话仅通过有上限、封印的匿名 memfd 传递；接收校验长度、类型、封印和成品一致性。普通恢复文件、PNG、剪贴板、钉图、OCR/翻译只使用遮挡合成后的成品，不附带原图工程或永久源图历史。
- 原预览关闭后编辑器应用仍能重新打开结果；若接收窗口无法创建，当前窗口必须留下图片和文字，而不是只发通知后退出。

## 输出设置

默认保存目录、文件名模板、区域完成后预览策略集中在截图与输出页。主页保留常用开关。目录选择取消不改设置；非UTF8目录拒绝，不用有损字符串替换路径。

模板支持 {kind}、{date}、{time}，自动附加微秒、必要的碰撞后缀及 .png。拒绝目录分隔符、控制字符、未知token和过长输入；普通百分号只当字面文本，不作为任意日期格式执行。区域、长图和钉图共用当前配置，另存为不修改默认目录。继续沿用三方合并和安全独占写图。

## 资源边界

- 编辑：24,000,000 像素，RGBA数据96,000,000字节；整幅栅格编辑高度最多32767，超过后可只读查看并先裁切。对象、点、文字和撤销历史另外有上限，按动作记录，不在每个鼠标motion克隆整张图。
- 长图：48,000,000像素 / RGB144,000,000字节，并限制高度262144；单个采集帧16,000,000像素 / RGB48,000,000字节。
- 队列仍单独限制96MiB；达到安全上限会停止追加并保留已可靠拼接的部分，明确提示剩余内容应分段截取。不会放宽匹配阈值或悄悄丢掉已拥有尾帧。
- 超过编辑预算的已有巨图仍可只读查看，并可先裁出预算内区域继续编辑。原始巨图不被改写。

以上是尺寸、像素和受控缓存载荷上界，不是实测总RSS封顶。后端首次采集/解码、编码暂存、GTK及GPU内存仍需要专项测量，未声称全部已覆盖。
