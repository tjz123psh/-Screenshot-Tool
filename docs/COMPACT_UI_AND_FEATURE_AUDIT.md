# 紧凑界面与功能完整性复查

> 本文记录该轮界面更新与当时的功能缺口；随后已完成的保存、恢复、设置和后台任务修复见[第一批可靠性修复](<RELIABILITY_PHASE1.md>)。

本轮针对“工作台太小、工具栏塑料感强、按钮大、标注混乱”进行改进，同时按实际实现检查功能缺口。下面区分已完成、验证方式和仍待补齐的内容。新版已于 2026-10-04 按用户要求安装到本机，四个程序与通过测试的 release 构建一致、相关服务已重启；没有恢复或改动已移除的 niri 快捷键。后续每轮验证通过后自动安装，见[项目交付要求](<../AGENTS.md>)。

## 界面与操作

- 设置工作台从 700×490 调整为 **800×560**，侧栏与文字一起放大；小屏仍会限制窗口尺寸，页面可滚动。
- 截图工具栏去掉强高光、双层倒角和厚底边；使用低对比石墨面、细边和轻阴影。按钮高度 30px，工具栏单行高度 38px。保留可点击面积，而不是只缩小字。
- 标注分为紧凑工具行和独立属性条。绘制、遮挡处理、撤销重做、返回/完成分组；快捷键不再常驻成一串小键帽，悬停可查看名称和按键。
- 画笔、箭头、矩形、椭圆显示颜色和线宽；文字显示颜色和字号；马赛克、模糊、取色不再展示无效颜色/大小设置。属性条直接显示数值。
- 无可撤销/重做内容时，按钮变灰且不可触发。返回选区或未编辑文字时按 Esc 会保留已画标注；清空仍可在选区状态右键进行。
- 弹层以整组工具栏为锚点，优先不遮住另一层工具；覆盖 320×240、480×270、640×360 等短窄显示区域的可达性回归。

## 本轮实际补齐与修复

### 1. 实色遮挡

新增 **实色遮挡（H）**，位于打码工具组，拖出矩形即以纯黑覆盖。覆盖范围向像素外侧取整，不保留半透明抗锯齿边；遮挡层置顶，后续模糊或马赛克不能重新取样显露被遮住的原图。即便在拖动尚未释放时确认，当前可见的遮挡也会进入导出。

用户仍须检查覆盖范围。置顶是有意的安全行为，因此也会盖住该区域内的后续文字或笔迹；明确撤销遮挡后才恢复原图。**模糊和马赛克仍只是视觉弱化，不替代实色遮挡。**

回归使用两种非均匀底图、三个选区位置、正反向和分数坐标拖动；检查预览、烘焙、PNG 编解码后的每个覆盖像素为不透明黑色，覆盖外像素不变，并验证撤销、重做、缓存重建和后续模糊。测试只处理生成像素。

### 2. 马赛克/模糊预览与结果错位

原实现把选区原点加了两次，选区不在左上角时，保存结果可能采到另一区域，靠屏幕边缘时甚至留下透明采样。现在源图和笔画始终按屏幕坐标取样，只在目标画布中做选区平移。

20 组裁切/方向组合与混合图层回归通过；马赛克和提交后重放完全一致。Cairo 模糊在屏幕预览与平移后的缓存间有最多 1 个 RGB 字节的插值舍入差，测试仅允许这项数值差，alpha 和原图恢复仍精确。没有降低模糊/马赛克强度来通过测试。

### 3. 标注输入错误

- 右键/中键不再启动滑块拖动；关闭弹层、切换工具、返回会清除拖动状态。
- 工具栏和弹层空白处不会点穿、误切工具或画出隐藏笔画。
- 输入文字时 Ctrl+Z/Y 不会被当成普通字母；撤销先取消未完成文字，不误删上一笔。
- 直接点击另一个文字位置时，输入法候选框跟随新位置；旧位置的组合输入被重置。

### 4. 截图输出保留

同时关闭自动保存和复制后，普通截图不再成功退出却丢掉图片，而是打开现有查看器。任何一项请求的导出失败，也会尝试保留查看器供重试；保存和复制仍独立尝试，成功项不会被另一项失败掩盖。错误提示区分操作且不展示原始路径、地址或任意后端错误文本。

注入式回归覆盖 32 种输出/失败/预览启动组合。当前分离进程机制只确认“进程已启动”，未实现“窗口已显示”的跨进程回执；如果临时文件交接或查看器本身无法启动，仍会明确报错，不能保证这种情况下保留图片。未对用户真实图片进行失败注入。

### 5. 设置与结果状态

- 托盘在轮询、菜单打开、执行截图和切换偏好前刷新设置，避免工作台改了设置，托盘仍使用旧值。切换一项时保留另一项最新值；真实同时写入仍缺跨进程事务。
- 翻译失败会解除忙碌状态、恢复按钮，保留已有 OCR/编辑文本，允许重新尝试。无真实 API 请求，使用状态回归测试。

## 确实已经具备的功能

区域框选/移动/缩放、基本绘制与中文文字输入、颜色/字号/线宽、取色、撤销重做、长截图与独立查看器、复制/保存/钉图、本地和 API OCR、API 翻译、模型列表与连接测试、托盘与设置保存均已有实现。本轮重点是修复它们的交接与状态，不把已有功能重复列成待开发。

## 仍缺或需要继续完善

1. **已有图片的后期编辑**：查看器目前只读；不能重新打开已导出的图片修改旧文字、移动单个图形、再裁切。
2. **更完整的文字/形状编辑**：目前文字主要是输入与退格，尚无文字选区、重新选中旧标注、字体选择、图形填充/透明度等对象级编辑。
3. **钉图和结果窗口的慢速 I/O**：部分复制/保存仍在 GTK 回调中执行，慢剪贴板或慢磁盘可能卡界面，需要像查看器一样迁到后台并提供可见错误状态。
4. **另存为的原子替换**：现有查看器对指定目标直接写文件，写入中断时存在损坏旧目标的风险。应先完整写临时文件，再替换目标。
5. **同时写设置的冲突处理**：本轮解决了陈旧缓存覆盖，但两个进程恰好同时保存时仍可能竞争，需共享事务/锁或合并协议。
6. **查看器启动回执与失败保留**：需要补上真实窗口就绪确认，以及查看器无法启动时仍能找回临时图的机制。

PNG 是当前输出格式，不把尚未支持的 JPG/WebP 导出做成可点击的假选项。多屏、混合缩放与 Hyprland 的本轮交互仍未实机验收。快捷键平台限制本轮不处理。
